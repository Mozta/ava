# AVA - Asistente Virtual Avanzado

## Proyecto Universitario

**AVA** es un proyecto de innovacion tecnologica desarrollado por estudiantes universitarios en el **Laboratorio de Inteligencia Artificial y Realidad Extendida**. Este asistente virtual representa la convergencia entre inteligencia artificial conversacional, vision por computadora y graficos 3D interactivos.

## Innovacion Tecnologica

AVA integra tecnologias de vanguardia para crear una experiencia de interaccion humano-computadora sin precedentes:

### Inteligencia Artificial Multimodal
- **Vision por Computadora**: Utiliza MediaPipe de Google para deteccion facial en tiempo real, permitiendo que el asistente reconozca y responda a la presencia del usuario.
- **Procesamiento de Lenguaje Natural**: Integracion con ElevenLabs AI para conversaciones naturales y sintesis de voz de alta calidad.
- **Respuesta Contextual**: El sistema adapta su comportamiento y respuestas basandose en el contexto visual y conversacional.

### Interfaz 3D Interactiva
- **Orbe de Particulas**: Nube de ~1800 particulas que forman un orbe etereo, reemplazando el concepto tradicional de avatar por una representacion visual abstracta y futurista.
- **Animaciones Expresivas**: El orbe transiciona entre estados con comportamientos unicos: respiracion (idle), compresion (escuchando), orbita caotica (pensando), formacion de ojos y boca (hablando), onda expansiva (saludando).
- **Transiciones con Glitch**: Las particulas migran gradualmente entre formaciones con micro-glitches aleatorios que aportan una estetica cyberpunk organica.
- **Seguimiento Facial**: El orbe rota siguiendo la posicion del rostro del usuario, creando la sensacion de que observa al interlocutor.

### Innovaciones Clave

1. **Interaccion Natural**: Combinacion de reconocimiento facial y conversacion de voz para crear una experiencia inmersiva.

2. **Feedback Visual en Tiempo Real**: El orbe proporciona retroalimentacion visual constante sobre su estado a traves de movimiento, forma y color de las particulas.

3. **Interfaz Cyberpunk**: Diseno visual futurista con estetica cyberpunk que refleja la naturaleza tecnologica del proyecto.

4. **Colores Configurables**: Sistema de configuracion centralizado que permite personalizar colores por estado, cantidad de particulas y parametros de comportamiento.

## Arquitectura del Sistema

El proyecto esta construido sobre una arquitectura modular que incluye:

- **Frontend Reactivo**: React 19 con hooks personalizados para gestion de estado compleja
- **Motor 3D**: Three.js con React Three Fiber para renderizado de particulas eficiente
- **Pipeline de IA**:
  - MediaPipe para vision por computadora
  - ElevenLabs para conversacion y sintesis de voz
- **Estado Predictivo**: Sistema de estados que anticipa y responde a las acciones del usuario

## Casos de Uso

AVA esta disenado para multiples aplicaciones en el ambito educativo y empresarial:

- **Asistente Educativo**: Guia interactiva para estudiantes
- **Recepcion Virtual**: Sistema de bienvenida e informacion
- **Prototipo de Investigacion**: Plataforma para explorar interacciones IA-humano

Este proyecto explora varias areas de investigacion activa:
