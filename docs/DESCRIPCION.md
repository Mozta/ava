# AVA - Asistente Virtual Avanzado

## 🎓 Proyecto Universitario

**AVA** es un proyecto de innovación tecnológica desarrollado por estudiantes universitarios en el **Laboratorio de Inteligencia Artificial y Realidad Extendida**. Este asistente virtual representa la convergencia entre inteligencia artificial conversacional, visión por computadora y gráficos 3D interactivos.

## 🚀 Innovación Tecnológica

AVA integra tecnologías de vanguardia para crear una experiencia de interacción humano-computadora sin precedentes:

### Inteligencia Artificial Multimodal
- **Visión por Computadora**: Utiliza MediaPipe de Google para detección facial en tiempo real, permitiendo que el asistente reconozca y responda a la presencia del usuario.
- **Procesamiento de Lenguaje Natural**: Integración con ElevenLabs AI para conversaciones naturales y síntesis de voz de alta calidad.
- **Respuesta Contextual**: El sistema adapta su comportamiento y respuestas basándose en el contexto visual y conversacional.

### Interfaz 3D Interactiva
- **Representación Visual Dinámica**: Robot 3D completamente animado que responde en tiempo real a las interacciones del usuario.
- **Animaciones Expresivas**: El avatar incluye movimientos naturales de cabeza, ojos, boca, brazos y cuerpo que se sincronizan con el estado conversacional.
- **Seguimiento Facial**: El robot mantiene contacto visual con el usuario mediante el seguimiento de su posición facial.

### Innovaciones Clave

1. **Interacción Natural**: Combinación de reconocimiento facial y conversación de voz para crear una experiencia inmersiva.

2. **Feedback Visual en Tiempo Real**: El robot proporciona retroalimentación visual constante sobre su estado (idle, escuchando, hablando, pensando).

3. **Interfaz Cyberpunk**: Diseño visual futurista con estética cyberpunk que refleja la naturaleza tecnológica del proyecto.

4. **Animaciones Procedurales**: Sistema de animación complejo que genera movimientos naturales y expresivos:
   - Parpadeo automático cada 5 segundos
   - Gestos con brazos al hablar
   - Movimientos corporales sutiles
   - Antena pulsante según el estado
   - Boca con múltiples frecuencias de movimiento

## 🏗️ Arquitectura del Sistema

El proyecto está construido sobre una arquitectura modular que incluye:

- **Frontend Reactivo**: React 19 con hooks personalizados para gestión de estado compleja
- **Motor 3D**: Three.js con React Three Fiber para renderizado 3D eficiente
- **Pipeline de IA**: 
  - MediaPipe para visión por computadora
  - ElevenLabs para conversación y síntesis de voz
- **Estado Predictivo**: Sistema de estados que anticipa y responde a las acciones del usuario

## 🎯 Casos de Uso

AVA está diseñado para múltiples aplicaciones en el ámbito educativo y empresarial:

- **Asistente Educativo**: Guía interactiva para estudiantes
- **Recepción Virtual**: Sistema de bienvenida e información
- **Prototipo de Investigación**: Plataforma para explorar interacciones IA-humano
- **Demostración Tecnológica**: Showcase de capacidades de IA y gráficos 3D
